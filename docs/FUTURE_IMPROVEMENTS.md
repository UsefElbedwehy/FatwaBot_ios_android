# Future Improvement Notes

Ideas consistent with the vision, deliberately out of the current roadmap. Revisit at each milestone review.

- **Live Activities / Dynamic Island** prayer countdown (iOS) — candidate for M4 polish if approved.
- **Apple Watch / Wear OS** companions: next prayer, tasbeeh on the wrist.
- **Ramadan mode**: suhoor/iftar countdown hero, taraweeh tracking, admin-scheduled seasonal content (Home spec already reserves the variant).
- **Adhan audio** with muezzin voice choices and per-prayer sound settings.
- **Mosque finder** (nearby masajid, iqamah times — needs a data partnership).
- **Qur'an module** (reading, bookmarks, khatmah tracking) — large scope; natural post-launch expansion of the Worship tab.
- **Social "circles"**: private family/friends challenge groups (guardrails of ADR-0007 apply).
- **On-device AI fallback** for offline hadith lookup once curated collections ship.
- **KMP domain extraction** — only if iOS/Android domain drift becomes a measurable bug source (see ADR-0001).
- **Web companion app** for azkar/prayer times (marketing + accessibility surface).
